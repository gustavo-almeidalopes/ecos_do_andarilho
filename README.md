<h2 align="center">🎮 Sobre o Projeto</h2>

**Ecos do Andarilho** é um jogo de plataforma desenvolvido na engine **Construct 3** como projeto acadêmico para a disciplina de **Desenvolvimento Mobile**.

O conceito é simples no enunciado e ousado na execução: **transformar obstáculos dinâmicos em desafio de precisão**. Cada inimigo, cada plataforma móvel e cada armadilha exige timing perfeito e reflexos aguçados para ser superada.

🎮 **Demo jogável:** [jogo-aula-de-mobile.vercel.app/game/jogo.html](https://jogo-aula-de-mobile.vercel.app/game/jogo.html)
🌐 **Landing page oficial:** [jogo-aula-de-mobile.vercel.app](https://jogo-aula-de-mobile.vercel.app/)

<h2 align="center">🚀 Como Executar Localmente</h2>

#### 1. Clone o repositório

```bash
git clone https://github.com/gustavo-almeidalopes/ecos_do_andarilho.git
```

#### 2. Acesse a pasta

```bash
cd ecos_do_andarilho
```

#### 3. Sirva os arquivos com um servidor local

```bash
# usando Python
python -m http.server 8080

# ou usando Node.js
npx serve .
```

#### 4. Abra no navegador

```
http://localhost:8080
```

> 💡 Para rodar diretamente o jogo, acesse `/game/jogo.html`
> 💡 Para a landing page, acesse `/index.html`

<h2 align="center">❓ FAQ</h2>

<details>
<summary><b>Por que Construct 3?</b></summary>

<br/>

A escolha foi pragmática: o sistema de **Eventos visuais** permite iterar muito rápido, e o suporte nativo para **HTML5** facilita o deploy e o teste em dispositivos móveis sem builds intermediárias.

</details>

<details>
<summary><b>Qual foi o maior desafio técnico?</b></summary>

<br/>

Sincronizar o spawn de inimigos e a movimentação de plataformas com os eventos de cada fase. A solução foi usar **Event Sheets do Construct 3** mapeando o tempo exato de cada ocorrência para variáveis globais (`Eco_Tempo`, `Eco_Estado`).

</details>

<details>
<summary><b>O jogo será lançado comercialmente?</b></summary>

<br/>

Não. *Ecos do Andarilho* é um **projeto acadêmico** desenvolvido para a faculdade. Serve exclusivamente como prova de conceito.

</details>

<details>
<summary><b>Como funcionam os controles mobile?</b></summary>

<br/>

O **Touch Plugin** do Construct 3 detecta dispositivos com tela tátil e renderiza botões semi-transparentes na HUD. Eles invocam funções análogas às setas do teclado, mantendo a paridade entre desktop e mobile.

</details>
