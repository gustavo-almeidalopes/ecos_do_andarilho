1. Visão Geral do Projeto

Ecos do Andarilho é um protótipo de jogo de plataformas 2D com mecânicas subjacentes de ritmo, desenvolvido como projeto de conclusão académico. A premissa técnica baseia-se na sincronização entre eventos físicos (gravidade, colisões) e o espetro de áudio (BPM).

Conceito Central: Variáveis Rítmicas
Os "Ecos" são momentos pré-programados onde o Tick da engine avalia o tempo do áudio. O ritmo não atua apenas como banda sonora, mas como o próprio controlador lógico de *State Machines* das entidades do jogo.

2. Arquitetura do Sistema

A solução divide-se em dois macro-componentes: O invólucro web (Landing Page / Front-end) e o *Core Runtime* do jogo exportado.

Frontend Wrapper

Desenvolvido em HTML5, CSS3 e JS (ES6). Utiliza variáveis CSS para Theme Switching e integra GSAP para manipulação direta do DOM.

Game Runtime

Exportação HTML5 do Construct 3. Roda num <canvas> isolado utilizando WebGL para renderização e Web Audio API para latência zero.

Behaviors & Lógica no C3

3. Engenharia de Mecânicas

A sincronização musical é o maior desafio técnico. Abaixo ilustramos em pseudocódigo a lógica implementada nas Event Sheets do Construct 3 para validar saltos rítmicos.

core_logic.js (Pseudocode)
// Global Variables let currentBPM = 120; let beatDuration = 60.0 / currentBPM; // 0.5 sec per beat let tolerance = 0.15; // 150ms window // On System Tick (Every Frame) function checkRhythmSync(audioPlaybackTime) { let timeSinceLastBeat = audioPlaybackTime % beatDuration; if (timeSinceLastBeat < tolerance || timeSinceLastBeat > (beatDuration - tolerance)) { return true; // Perfect Echo Jump } return false; // Missed beat } // On Player Jump Input if (Input.isActionPressed('Jump')) { if (checkRhythmSync(Audio.playbackTime)) { Player.setJumpStrength(800); // Boosted jump } else { Player.setJumpStrength(500); // Weak jump penalty } }

Heróis & Estados

  • Kaelen (Base): Física padrão de gravidade (Gravity = 1500).
  • Lyra (Nuvens): Engatilha Set Gravity to 0 e inicia um Timer behavior de 2 segundos.
  • Grom (Tank): Controlo booleano isShielded verificado antes da dedução de HP.

4. Infraestrutura & Deploy

O repositório está integrado de forma nativa com a plataforma Vercel para Continuous Deployment (CD). O cabeçalho otimiza a cache dos ficheiros `.json` pesados.

vercel.json
{ "cleanUrls": true, "headers": [ { "source": "/game/images/(.*)", "headers": [ { "key": "Cache-Control", "value": "public, max-age=31536000, immutable" } ] } ] }
